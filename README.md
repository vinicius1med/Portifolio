MEU PORTIFOLIO

Este projeto contempla uma aplicação simples utilizando "Flask - python" que apresenta todos os conteudos e atividades de meu desenvolvimento durante o segundo semestre 2024/2025 (TADS 4).
   
Tecnologias utilizadas:

      - Flask (python);
      - Python;
      - JavaScript;
      - HTML + CSS;
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------

COMO USAR?

Para testar localmente:
1. De início será necessário clonar o presente repositório para uso em seu VS Code.

         > git clone https://github.com/vinicius1med/Portifolio.git
2. Agora acesse a pasta "Portifolio".

         > cd Portifolio
3. Inicie uma máquina virtual python (virtual environment) no diretório do projeto com o comando.

         > python -m venv nome_da_maquina_virtual
4. Ative a máquina virtual:

         > nome_da_maquina_virtual\Scripts\activate #Windows
         > source nome_da_maquina_virtual/bin/activate #Linux/MacOS

5. Instale as dependências do projeto listadas no arquivo requirements.txt utilizando o comando:

         > pip install -r requirements.txt

6. Execute o arquivo principal da aplicação com o comando:

         > python app.py

7. Acesse a rota disponibilizada no terminal para visualizar e interagir com a aplicação.

8. E pronto, voce ja pode testar meu projeto!
